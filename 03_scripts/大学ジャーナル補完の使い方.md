# 大学ジャーナル補完の使い方

`publish_university_journal.cmd` をダブルクリックすると、PCから大学ジャーナル
オンラインのRSSを取得し、GitHubにある最新の公表用JSONへ追加する候補を作ります。

## 安全確認の流れ

1. 最初の確認では `Y` を入力します。
2. GitHubの既存記事数、PCで取得できたRSS件数、新規候補のタイトルを確認します。
3. 公開してよい場合だけ、2回目の確認で `PUBLISH` と入力します。
4. 構文検査・単体テスト・GitHubの競合確認がすべて成功した場合だけ公開します。

途中で別の文字を入力した場合、RSS取得やテストに失敗した場合、またはプレビュー後に
GitHubが更新された場合は、GitHubの公表JSONを変更せず停止します。

新たに補完する記事では、記事本文やRSS概要を公開せず、タイトル、媒体名、公開日、
分類、元記事へのリンクだけを追加します。SQLiteデータベースはGitHubへ送信しません。

公開が成功すると、Streamlit Community CloudがGitHubのJSONを読み直し、通常は数分以内に
公開サイトへ反映します。
